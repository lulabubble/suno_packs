APPENDIX — DELETE WHEN REMIXING

PHONETIC PRINCIPLE (bridge):
Compressed lines read as one continuous phrase. Removed vowels
are silent; consonants glue to the next word. The [ref:] line
above gives intended word breaks — read across without pausing.
The rhythm never changes: only what the voice would skip anyway.
Rule of thumb: merge only where a syllable is actually saved.
One-syllable function words (and, then, I, am) stay separate —
"andthen" saves nothing and creates a reading risk.

SAFE-VARIANTS PRINCIPLE (bridge):
If a model glitches, restore the shortest readable form of the
swallowed word (is → 's → s; "a door" → ador → adoor; every →
evry). Priorities: keep syllable count, keep stress pattern,
restore only mis-sung letters. Never lengthen the rhythm. Apply
per line: "unzip one letter at a time until the glitch clears."
Merging must not produce a different English word
(aversion ≠ a version). If the merged form is itself a word,
drop the leading vowel instead (a version → vrsion).

AFTER-BRIDGE PRINCIPLE (final chorus):
The final chorus repeats the words of the earlier choruses
verbatim. What changes is delivery: belt from the first line,
added harmony, layered vocals. Not a new text. The refrain is
the same knowledge — the first time as a question, the last
as a fact.

UNDERSTATEMENT PRINCIPLE (outro):
The outro does not conclude — it decays. The voice stops
finishing words, lines, thoughts. Silence becomes content.
Applied per line: cut at the point where the voice would
naturally run out. Never lengthen. If a fragment returns,
it returns smaller. The song stops; it does not end.
The outro demonstrates the principle — read it as one
continuous decay, not as separate sections.
